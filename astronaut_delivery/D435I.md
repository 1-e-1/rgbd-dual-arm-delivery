# D435i 左臂适配

## 交付入口

- 静态装配：`isaacsim_model/astronaut_delivery_d435i.usd`，叠加原 workcell，不覆盖原装配。
- 官方外壳：`isaacsim_model/sensors/d435i/d435i.usdc`。原始 DAE、URDF、Apache-2.0 LICENSE 保留在 `source/`；固定提交、SHA-256 和转换说明见 `provenance.json`。官方 D435i URDF 复用 D435 外壳并增加 IMU。
- 参数：`configs/d435i.json`。所有相机内外参、安装位姿明确标为 **NOMINAL_SIMULATION_ONLY**，不是实机逐台标定。
- 算法：`d435i.py`（双流传感器与视角评分）、`vision.py`（建图和视觉目标）、`run.py`（联动和安全状态机）。不加载 PPO、世界模型、CFM 或 Drifting 权重，不需要重新训练。

## 参数和坐标

| 项目 | 当前配置 | 性质 |

| 原生深度 | 848×480，30 FPS，标称 87°×58° | 近似仿真内参，实机从 SDK 读取 |
| RGB | 1280×720，30 FPS，标称 69°×42° | 与深度不同的内参/光学中心 |
| IR 基线 | 50 mm | 标称机械参数 |
| 有效建图深度 | 0.30–2.0 m | 工程截断，不是官方极限距离 |
| 目标观测距离 | 0.45–1.20 m，偏好 0.8 m | 对已观测目标的约束，不保证未知遮挡物距离 |
| 深度融合 | 原生 848×480；12 mm TSDF，0.5 s 更新间隔 | 沿用递送原型精度，不代表已达到规划精度 |
| 视觉控制 | 15 Hz 处理；关节运动学 60 Hz | 仿真时间频率，不等于当前 Python 实时吞吐 |
| 左端安装 | 深度光心在 b8 局部 z=92.88 mm | 为外壳/适配座预留空间的假定值，待测量 |

世界坐标仍为 X 向前、Y 向宇航员左侧、Z 向上。USD 相机用 OpenGL：X 右、Y 上、−Z 前；RealSense 原始 optical frame 用 X 右、Y 下、Z 前。两者转换为 `diag(1,-1,-1)`，不是翻转世界坐标。RGB 光心相对深度 OpenGL 坐标约为 `[-0.015,0,0] m`。IMU 只提供参考坐标，不将加速度积分伪装成可靠世界位姿。

USD 内参通过焦距和两个 aperture 独立设置；`fx != fy`，不能只改水平 FOV。原始 CAD 将镜头盖建成实体表面，光心位于盖后约 4.3 mm，因此渲染近裁剪为 10 mm 以越过自身盖板；真实有效测距下限另行截断为 0.30 m。

## 核心算法

深度反投影（OpenGL）：

`p_D = [(u-cx)z/fx, -(v-cy)z/fy, -z]`，`p_W = T_WD p_D`。

RGB 与深度不先裁成同一窄视场。将深度点投影到 RGB：

`p_C = inverse(T_DC) p_D`，`u_C = fx_C*x_C/(-z_C)+cx_C`，`v_C = -fy_C*y_C/(-z_C)+cy_C`。

仅在 RGB 边界内且渲染深度一致时赋色。没有对应 RGB 的有效深度依然建图；无效深度为 0，不补洞、不将未知空间标为自由空间。仿真同时射线检测两个 IR 光心，剔除立体重叠区外及遮挡不一致点。它是几何近似，**不是实际立体匹配器**。

仿真噪声采用可复现的工程假设：

`sigma_z = sigma_floor + z^2 * sigma_disparity / (fx * baseline)`。

默认 `sigma_floor=0.5 mm`、`sigma_disparity=0.04 pixel`，另有 0.5% 丢点。上述数值不表示厂家精度保证。真实反光金属、黑色表面、边缘混合像素、强光和曝光失配可能更差。

左臂只考虑少量可达候选视角，避免引入复杂策略网络：

1. 初次用配置的工作区中心引导，不读取零件真实位姿；随后使用 RGB-D 得到的目标位置。
2. 求 IK，检查自身/环境碰撞，并由右臂安全监督器检查两臂干涉；相机外壳和安装座都作为末端碰撞体。
3. 对已观测目标约束工作距离、RGB 画面边缘余量，并惩罚关节位移。评分为 `2*最小归一化边缘余量 - 0.2*平均距离偏离 - 0.015*关节位移范数`。这是几何启发式，不是信息熵收益或学习奖励。
4. 左臂停稳后等待三个处理周期，检查工作区有效深度比例；至少进行两个不同视角的初始观测。视角数有限，观测不足则停止，不无限移动寻找。
5. 已知彩色磁吸帽使用颜色比例和深度估计位置，保留部分遮挡/大跳变拒绝、新鲜度门控和每次最多 25 mm 的视觉逼近。
6. 建图按已知机器人 CAD/FK 生成自体掩膜并膨胀 2 像素，防止移动机械臂污染地图。**这是仿真自体掩膜，实机还需要实现投影深度一致性和标定容差验证。**
7. 右臂持物时不移动左臂、不融合移动物体；物体转移完成后重置静态图，避免残影。右臂的 CAD 安全模型与感知图分离，不能把递送成功当成“仅靠未知环境建图即可保证安全”。

Observation：深度 `[480,848]` float32（m）、对齐颜色 `[480,848,3]`、`K[3,3]`、`T_WD[4,4]`、时间戳、颜色有效掩膜和机器人掩膜；原生 RGB `[720,1280,3]` 保留用于核对。State：双臂 `q[2,8]`、地图、目标估计/协方差、持物状态。Action：左臂候选视角对应 `q[8]`；右臂有界 Cartesian 修正经 IK 输出 `q[8]`。Reward/Loss：无训练奖励和神经损失；使用上述视角评分及位置/轴向 IK 最小二乘。

```text
reset fixed kinematic scene; load nominal D435i profile
for two distinct safe candidate views:
    pause right arm; certify left trajectory including camera housing
    move left; settle; acquire native depth and native RGB
    reject stereo-invalid/range-invalid points; register color onto depth
    reject poor view; remove robot pixels; update static TSDF and targets
for each task part:
    require fresh visual target; try bounded reacquisition only if empty-handed
    right: approach -> bounded visual corrections -> proximity-confirmed attach
    right: lift -> transfer -> place -> detach -> retract
    throughout: certified trajectory, per-tick collision supervisor, stale-data stop
    reset static map after relocation; reobserve
```

## 运行、验证与实机边界

在 `D:\work_space\lunwen2` 使用现有环境：

```powershell
& D:\conda_envs\env_isaaclab\python.exe -m astronaut_delivery.d435i_scene
& D:\conda_envs\env_isaaclab\python.exe -m astronaut_delivery.run --sensor d435i --output reports/d435i_new_run
& D:\conda_envs\env_isaaclab\python.exe -m astronaut_delivery.d435i_validate --run reports/d435i_new_run
& D:\conda_envs\env_isaaclab\python.exe -m astronaut_delivery.preview --run reports/d435i_new_run --frames 100
& D:\conda_envs\env_isaaclab\python.exe scripts/check_delivery_isaacsim.py --run reports/d435i_new_run
& D:\conda_envs\env_isaaclab\python.exe -m pytest -q --basetemp reports/pytest_d435i_new
```

每次选择新输出目录。`--sensor legacy` 可回归旧传感器，但同样应指定新目录，避免覆盖原验证成果。渲染共享同一次曝光的场景 BVH，不跨时间复用移动几何；回归检查与独立 BVH 渲染逐像素一致。

控制种子 `20260906`，IK/RRT/深度噪声固定种子；噪声静态消融使用 `17,41,20260906`，比较 1× 与 3× 噪声下两个视角的彩色帽中心误差。真值只在独立 `d435i_validate.py` 中作为评测标签。单场景成功不表示泛化成功率，不替代随机物体/距离/照明/材质/遮挡统计。事件日志、轨迹、图、视角质量、噪声消融和原生 RGB 截图均保留。

实物 D435i 接入前，用官方 SDK 安装了 `pyrealsense2` 的采集环境执行：

```powershell
python scripts/capture_d435i_calibration.py --output reports/d435i_unit_calibration
```

该脚本只启动相机并导出实际 intrinsics、畸变模型、depth scale、depth→color extrinsics、固件/序列号、时间戳和原始帧；不连接机械臂，不修改设备标定，不覆盖已有输出。目前工程环境缺少此可选 SDK，未进行实机采集。导出文件不能直接解除运动安全门禁：还需实现/验证畸变处理，测量末端安装和 `T_b8_depth` 手眼标定，按曝光时间插值真实关节编码器 FK，并测量 USB/控制通信延迟。不要把相机采集到达时间当成曝光时间。

上机必须独立验证硬件急停、速度/加速度/关节限位、磁吸传感器反馈、相机和线缆包络、宇航员安全距离、深度误差预算与未知区禁入。当前 3 mm CAD 裕量、12 mm 递送原型 TSDF 和模拟 8 mm 吸附条件，不能未经验证直接用于真实人机协作。Isaac Sim 静态 RTX 加载测试与 Python 运动学回归是两种不同证据；本版本不是 IsaacLab 强化学习训练任务。

## 本次验证结果

本次运动学回归见 `reports/astronaut_delivery_d435i_verified/`：3/3 零件完成，93.8 s 仿真时间，1137 次观测、13307 次碰撞检查，完整运动启用连续区间认证。吸附确认距离分别为 4.03、4.24、4.26 mm；这不是实机定位精度。初始两个视角距三个目标约 0.77–1.09 m，没有贴近零件观察。101 项全工程测试通过。

共享场景 BVH 优化后的完整流程也重新执行通过，保存在 `reports/d435i_optimized_confirmation/`；轨迹和事件文件的 SHA-256 均与首次通过的运行完全一致。验证总表见 `verification_summary.json`，分别记录通过、超限与未验收的项目。

静态三种噪声种子的最大帽中心误差：第一视角标称噪声 6.54 mm、3× 噪声 9.97 mm；第二视角分别为 4.48 mm、6.94 mm。压力组第一视角超出 8 mm 吸附阈值，报告明确标为超限，不能将总流程 PASS 解释为所有噪声条件下都可靠。原生 RTX 结果以同目录 `native_render_result.json` 为准；不能用射线预览替代该项。

本次原生 RTX 检查 **未通过**：Kit 日志出现 `SharedMutex.cpp` 断言，随后未完成截图，360 s 看门狗仅终止自己启动的子进程。没有生成本版本的原生 RTX 截图。旧场景的历史原生渲染报告也有该断言，但不能据此判定本次具体根因；没有通过升级/修改外部 Isaac Sim 安装来绕过问题。当前已验证的是 USD 结构/相机 FK、射线观测和纯运动学递送，不包含新的 RTX 成像验收。
