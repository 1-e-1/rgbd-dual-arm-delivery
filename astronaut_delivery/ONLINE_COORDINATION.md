# 双臂在线协同与低基座反作用：第一轮实现

更新：2026-09-08。用户确认单模块质量为 **0.25042 kg**。本次为运动学控制与反作用估计实验，不是新一轮 PPO 训练，也不是硬件驱动。

## 当前交付及未完成项

1. 已实现左右臂共享同一控制步的 16 维关节加速度优化、独立视觉生产线程、带曝光时间戳的观测交接，以及两臂同时运动的连续碰撞/制动路径检查。
2. 已实现以 C 形件原点为共同参考的六维合成反作用估计；动量导数与独立逐刚体 Newton–Euler 计算通过数值交叉验证。
3. 已完成同一起点、同一视觉噪声种子的短程预抓取接近对照，低反作用目标明显降低该实验的反力/力矩。
4. **未达到实时截止期，未完成全程在线抓取—递送，未证明严格零反作用。** 不应将本报告的 `PASS` 理解为整机系统验收。

旧串行版本和既有成功/失败报告均保留。新场景为 `isaacsim_model/astronaut_delivery_online.usd`；回放为 `astronaut_delivery_online_demo.usd`。新场景显式设置米和 Z-up，修正旧 D435i wrapper 缺少显式单位元数据的问题，未改写历史场景文件。

## 执行流程

```text
独立视觉线程：D435i RGB-D → 目标测量 → 不可变、带曝光时间的最新观测
                                          ↓
双臂当前 q/v → 右臂接近目标 + 左臂注视/距离任务 + 合成反作用代价
                                          ↓
                         16 变量加速度 QP
                                          ↓
          双臂整段连续碰撞检查 + 下一状态可执行停车检查
                       ↓通过                  ↓不通过/视觉过期
              同步更新左右臂             执行已检查制动轨迹
```

视觉线程有独立 USD Stage，避免渲染线程读取控制线程正在修改的场景。控制端不将旧观测的曝光时间改为接收时间。目标来自 RGB-D 估计，不把零件 CAD 位姿作为视觉测量；碰撞检查仍使用已知仿真 CAD 几何，**尚不是完全由在线点云支持的未知环境避障验证**。

当前只验证工作位附近约 4 cm 的粗接近。起始关节角读取旧报告 `bolt/approach` 的最后一帧，随后所有动作由新控制器求解；这不是复播旧轨迹，但起始工作位是仿真重置，尚未验证从收拢位在线到达。

## 模型与公式

### 观测、状态、动作

- Observation：全幅启动深度 `[480,848]`、RGB `[720,1280,3]`；近目标跟踪采用深度/右 IR `[160,160]` 和 RGB `[320,320,3]` 的原生像素 ROI。ROI 只调整主点，不改变焦距、不伪装成变焦；实物端应裁剪接收到的图像。
- 目标观测：位置 `[3]`、协方差 `[3,3]`、曝光及可用时间标量。协方差用于数据合法性检查，**尚未用于 chance constraint**。
- State：两臂 `q,v ∈ R^16`，上一动作 `a_prev ∈ R^16`；分别前 8 维左臂、后 8 维右臂。
- Action：`a ∈ R^16`，通过常加速度段积分生成关节位置/速度，不输出电机力矩。
- 右臂任务：TCP 位置 3 维 + 工具轴方向 3 维，Jacobian `[6,16]`；方向向量约束仅有 2 个独立旋转自由度，不锁定绕工具轴自转。
- 左臂任务：归一化图像位置 2 维、目标距离 1 维、相对目标的仰视高度比 1 维，Jacobian `[4,16]`。高度比约束依赖当前任务已知的水平对接面假设，尚未推广任意倾斜目标。
- Reward / 训练 loss：本版本不训练策略，无 RL Reward；使用下述在线优化目标。

令 C 形件固定于惯性参考系，在其共同原点和坐标轴表达双臂总动量：

\[
H_C=A(q)v,\qquad A=[A_L\ A_R]\in\mathbb R^{6\times16}.
\]

单个刚体对线动量、角动量矩阵的贡献分别为

\[
A_{p,i}=m_iJ_{v,i},\qquad
A_{h,i}=I_i^WJ_{\omega,i}+[r_i-r_C]_\times m_iJ_{v,i}.
\]

旋转至 C 坐标轴后累加。无重力、无其他外部作用时，机械臂对 C 的反作用为

\[
W_C=\begin{bmatrix}F_C\\\tau_C\end{bmatrix}
=-\left(A(q)a+\dot A(q,v)v\right).
\]

这保留运动学命令生成，但加入刚体惯性计算；**只凭运动学和质量、不使用质心/惯量，不能可靠计算全部反力矩**。当前质量按用户确认值，质心、主惯量及主轴读取 USD，尚未进行实物独立标定。每臂 16 个质量刚体合计约 4.00672 kg，包含静止基座模块；静止部分不贡献运动反作用。具有相同运动链的固定刚体用平行轴定理精确聚合，原始刚体保留用于独立检查。

按用户要求暂不计摄像头、安装适配件、磁吸执行器、负载的质量/惯量，**不删除它们的碰撞几何**。不计吸附接触冲击、转子内部动力学、宇航员运动、基座柔性，因此这不是完整的自由漂浮宇航员动力学模型。

任务期望加速度采用 `b*=Kp(x*-x)-Kd Jv-Jdot v`。每步求解

\[
\min_a\ \|W_R(J_Ra-b_R^*)\|^2
+\|W_L(J_La-b_L^*)\|^2
+\lambda\|D(Aa+\dot A v)\|^2
+0.02^2\|a-a_{prev}\|^2+10^{-7}\|a\|^2.
\]

`D=diag(1/Fs,1/Fs,1/Fs,1/Ts,1/Ts,1/Ts)`。当前 `Fs=1 N`、`Ts=0.1 N·m` 是单位归一化参数，不是已验证的安全限值。右臂权重 `[100,100,100,10,10,10]`；左臂 `[10,10,3,10]`。`λ=0` 为消融基线，`λ=100` 为当前低反作用方案。

QP 包含关节位置、速度、加速度、普通运行 jerk 限制及相机视野特征的线性化约束。另预留 jerk 制动所需的速度余量。碰撞暂不直接写入 QP；候选动作必须经过保守连续检查和停车路径检查才能执行。不通过则制动，不保证绕障规划的完备性。

积分：`q_next=q+v*dt+0.5*a*dt²`，`v_next=v+a*dt`。连续检查包括段内速度反向时的位置极值，不能只检查起止姿态。双方同时移动的碰撞膨胀量同时计入；不是把另一臂视作静止。

停车采用公共停止时间 `T=max(abs(v))/a_stop`、`a_stop_vec=-v/T`，并检查整条轨迹。**该有限加速度停车不保证普通 jerk 上限**，因此尚不满足严格无冲击停车要求，不能直接部署硬件。

## 参数、时钟和计算量

配置文件：`configs/online_coordination.json`。

| 参数 | 当前值 / 解释 |
| --- | --- |
| 控制 dt | 1/60 s，设计值，不是已实现的壁钟频率 |
| 视觉频率 | 15 Hz 目标，启动全帧，之后 ROI |
| simulated 延迟 | 66.7 ms 注入延迟 |
| 观测最大年龄 | 250 ms，自曝光开始计算 |
| 速度 / 加速度 / jerk | 0.30 rad/s；0.50 rad/s²；5 rad/s³ |
| 关节范围 | 当前实验使用 ±π，实物部署前须核对每轴机械限位 |
| 相机距离 | 0.45–1.20 m；软目标 0.85 m |
| 粗接近目标 | TCP 在视觉测得的对接面上方 70 mm |
| 实验时长 | 最多 8 s，达到粗接近条件后执行已检查停车 |
| 种子 | 20260908；每次观测按帧索引派生噪声种子 |
| 数值线程 | threadpoolctl 限制 BLAS 为 1；OSQP warm-start |

`simulated` 模式验证算法和注入延迟，不提供实时证据。`wall` 模式中视觉线程独立生产最新观测；控制仍以固定仿真 dt 积分。当计算超时时，物理时间与仿真时间不同，反作用数值也只能解释为仿真时间下的估计。程序会记录超时，**没有可安全处理这些超时的实物控制驱动**。

ROI 阶段暂停全局 TSDF 更新，仅使用启动地图并优先跟踪目标；持续后台建图与全程递送任务状态机尚未接通。不得据此声称已解决动态未知环境中的实时建图引导。

该小实验反力峰值降低约 82.8%，力矩峰值降低约 83.4%，代价是略长时间和较小的相机接近幅度。**这不是严格零反作用，也不是对高精度抓取、随机场景或完整任务的性能承诺。** 表中约 10 mm 是粗接近目标残差，不是相机测量误差，更不是吸附成功误差。

不能只看起止静止动作的全程净冲量接近零；正负反力可能抵消。报告还记录峰值、RMS、积分模长和滑窗矢量冲量。

后续必须依次通过以下门槛：

1. 固定几何与安全裕度不变，降低连续避碰和停车认证成本，验证完整周期 P95/P99/最大值及故障时延；当前未过关。
2. 接入完整在线任务状态机、后台全局建图、吸附与递送；恢复全任务视觉质量/碰撞/制动验收，不能直接沿用旧串行结果。
3. 验证 jerk 连续的低反作用停车，再扩展多起点、多目标、多姿态与质量/惯量扰动。消融至少包含 λ=0/100、串行/同步、固定视角/目标视角、视觉延迟及掉帧；所有组报告任务成功率与基座峰值，不能只报单段最优值。
4. 实物前标定关节限位、手眼、每轴坐标、COM/惯量、通讯延迟和 D435i 噪声；加入独立急停、看门狗及硬件低速隔离试验。宇航员运动、C 结构柔性、吸附接触冲击需要独立模型和验证。

本次结果是本工程实测证据；“增加低反作用代价即可在全部场景达成零冲击”没有得到证明，也不作为论文新颖性声明。
