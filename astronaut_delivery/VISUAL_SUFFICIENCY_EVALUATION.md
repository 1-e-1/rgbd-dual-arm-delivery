# 视觉充分性、双臂反作用与随机场景：实现边界和计算流程

日期：2026-09-08。依据当前 `cooperative.py`、`vision.py`、`reaction.py`、`simultaneous.py`、`smooth_path.py`，不是未来算法的实现声明。

后续新增了 opt-in 研究分支 `sufficiency_delivery.py`。下文“尚未实现”描述的是此处审计的原默认控制器；新分支的局部集合约束、等时消融和未完成项见 [研究计划](research/RESEARCH_PLAN.md) 与 [探索性论文草稿](research/PAPER_DRAFT.md)。默认完整控制器没有被研究原型替换。

## 1. 现在能否使用所提出的研究表述

目前只能部分成立。建议采用：

> 在已知几何的固定基座运动学仿真中，双臂依据在线 RGB-D 观测协同递送；视觉臂利用局部冗余运动，并结合轨迹时间缩放，降低 C 基座的双臂合成惯性反作用。已验证场景的执行路径通过连续几何检查，独立视觉进程版本的流式控制计算满足所测周期预算。

不宜直接升级为“满足最小必要视觉质量时主动释放自由度，并在遮挡、避碰和有限计算预算下保持在线可行”。差别不是措辞，而是下列实现尚缺：

| 所需性质 | 当前实现 | 尚不能声称的内容 |
| --- | --- | --- |
| 最小必要视觉质量 | 新鲜度门控、圆弧支持检查、端点距离检查；本轮增加质量诊断 | 经任务误差预算推导的视觉充分集合，以及运动全过程的硬约束 |
| 主动释放视觉自由度 | 保持相机完整位姿的一阶 Jacobian 零空间修正 | 根据质量裕量主动解除不必要的相机位置/朝向等式约束 |
| 低合成反作用 | 双臂动量代理优化 + 时间缩放；记录完整反力/力矩 | 严格零反作用、全局最优，或已分离证实“自由度释放”的独立收益 |
| 遮挡应对 | 可见圆弧拟合、过期后重观测、三帧一致性重捕获 | 任意遮挡下持续可见、全过程视觉可行，或任意动态目标跟踪 |
| 避碰 | 当前已知 CAD 场景上的双臂连续段认证 | 仅凭当前部分点云即可证明未知环境的安全性 |
| 有限算力 | 低频规划和高频执行分离；异步传感器 | 全链路硬实时、规划始终按期返回、递归可行性证明 |

更有研究价值的目标，正是把第一、二行变成真正的 **任务充分视觉集合约束**，而不是继续增加串联滤波和规划模块。

## 2. 当前输入、输出与运行条件

- 输入：D435i 标称模型的 RGB、深度、内参、相机外参、曝光时间；双臂编码器位姿；任务阶段和已确认吸附状态。
- 估计量：对接中心 `p_hat[3]`、协方差 `Sigma[3,3]`、点数、时间戳；TSDF 局部环境地图。
- 状态：`q, v, a` 各 16 维，左右各 8 DOF，固定 C 形件和宇航员。
- 输出：左右臂同周期运动学位置/速度/加速度参考，不输出电机力矩。
- 单模块质量 0.25042 kg；每臂 16 个有质量模块合计 4.00672 kg。COM、惯量和惯量主轴来自 USD，未独立实测。相机、磁吸工具和负载惯量按用户要求不计，碰撞几何仍计入。
- 本支路不加载 CFM / Drifting / PPO / World Model；训练 loss、Reward 不适用。
- 主控制周期 1/60 s；视觉请求 15 Hz；地图更新间隔不短于 0.5 s。静止用全幅，运动中优先原生像素 ROI。
- 无重力、无接触动力学、无基座柔性和宇航员运动。本次是 USD 几何 + Warp 射线传感器 + 运动学控制实验，不是 PhysX 接触力或实物 D435i 标定验证。

## 3. 每一步怎样计算

### 3.1 RGB-D 反投影与对接面估计

深度为轴向深度 `z>0`，工程相机采用 OpenGL 的 `-Z` 前向：

\[
p_c=\begin{bmatrix}(u-c_x)z/f_x\\-(v-c_y)z/f_y\\-z\end{bmatrix},\qquad p_w=R_{wc}p_c+t_{wc}.
\]

RGB 与深度按各自标称内外参配准。无效深度、自身遮挡和不可靠颜色对应剔除。当前按已知颜色识别三个标准磁吸接口，不读取仿真目标中心作为视觉测量。

每个颜色连通区域取世界高度的高分位表面带，得到顶面点集 `P_top`。已知磁吸圆盘半径 `r=0.020 m`，从其 XY 凸边界提出圆心候选，按圆弧一致性筛选，再稳健优化：

\[
\hat c=\arg\min_c\sum_{j\in\mathcal I}\rho\big(\|b_j-c\|-r\big),\qquad
\hat p=\begin{bmatrix}\hat c_x&\hat c_y&\operatorname{median}(P_{top,z})\end{bmatrix}^{T}.
\]

这样半个圆盘被遮挡时，不会简单地把剩余可见点的质心当成真实圆心。拟合不足则不产生新估计。当前近似协方差为：

\[
\Sigma=\operatorname{Cov}(P_{top})/n+(0.002)^2I+\sigma_d^2 I.
\]

这里的协方差是工程估计，不是经覆盖概率标定的误差保证。正常更新采用 `0.25 p_new + 0.75 p_old`；新点数低于旧点数 40% 或中心跳变超过 6 mm 时拒绝。旧目标过期后，需三帧新中心在 3 mm 内一致才能重新建立目标。新视觉伺服目标要求观测年龄不超过 0.25 s。

### 3.2 TSDF 环境建图

将体素中心 `x` 投影到深度图，计算轴向残差，单位为米：

\[
d_k(x)=\operatorname{clip}\left(D_k(\pi(T_{cw}x))-z_c(x),-\mu,\mu\right),\quad\mu=0.036\;m.
\]

仅处理有效视域和截断带内的可靠测量。平滑区域用双线性深度，边缘用最近像素并降低权重，避免把前后景混成中间伪表面。逐体素加权融合：

\[
\phi_{k+1}(x)=\frac{w_k\phi_k+\Delta w_kd_k}{w_k+\Delta w_k},\qquad
w_{k+1}=w_k+\Delta w_k.
\]

`Delta w` 含边缘降权、已有证据上的稳健残差权重和权重饱和上限。表面点由相邻已知体素的符号变化做零交叉插值。

当前协作分支体素 **12 mm**，工作区 `[0.25,1.0] × [-0.72,0.48] × [0.65,1.60] m`。这不是另一独立 Planning v3 实验的 4 mm 配置，也没有在此次任务中验证 3 mm 级环境表面精度。吸附/放置后地图版本更新，清除旧静态证据；携带物通过测量颜色屏蔽，避免产生静态拖影。未知体素不当作自由空间，地图未观测背面也不凭空封闭。

### 3.3 右臂分段视觉引导

先观测目标，求距其上方 11 cm 的预抓取 IK。每轮重新观测后，设 TCP 为 `p_R`：

\[
e=\hat p-p_R,\qquad\Delta p=e\min\left(1,\frac{0.025}{\|e\|}\right).
\]

用 `p_R+Delta p` 和末端朝向求下一段 IK，最多十次接近。吸附以独立仿真近距条件确认，阈值 8 mm；不能只因视觉误差变小就强行吸附。后续为携物抬升 8 cm、递送、放置、撤离 12 cm。放置槽位是任务配置的已知目标，并非视觉识别出来的未知目的地。

这是 **持续感知、分段闭环更新目标**：两臂可同时执行，但不是每个 16.7 ms 周期都对任务状态重新求解全局优化。

### 3.4 左臂视觉目标与当前冗余修正

未吸附时，相机关注视觉估计中心；吸附后根据编码器 FK 和已确认连接关系预测携带目标的段内中间位置。先形成观察位置候选：

\[
p_{cam}^{des}=0.7p_{cam}+0.3\left(\hat p+\hat d\,\operatorname{clip}(\|p_{cam}-\hat p\|,0.65,0.90)\right).
\]

方向 `d_hat` 来自相机到目标的当前相对方向，抬高其竖直分量后归一化；光轴朝向目标。求位置 + 光轴 IK，单段相机关节候选最大变化 0.12 rad。

然后计算左臂完整位姿 Jacobian，注意不仅是光轴：

\[
J_L=\begin{bmatrix}J_v\\J_\omega\end{bmatrix},\qquad N_L=I-J_L^+J_L.
\]

一般满秩时是 `8−6=2` 个局部冗余方向，实际以 Jacobian 的秩为准。设两臂候选位移 `d=[Delta q_L;Delta q_R]`，合成动量矩阵为下一节的 `A`：

\[
D=\operatorname{diag}(1,1,1,10,10,10),\quad B=DA_LN_L,
\]

\[
\delta q_L=-N_L(B^TB+0.1I)^{-1}B^T D A d.
\]

这对应带正则的线性动量代理最小二乘，不是完整反力峰值最优化。修正最大分量限制 0.035 rad，随后精确 FK 检查目标距离 0.45–1.20 m，并交给联合碰撞认证。`J_L delta q≈0` 只是一阶保持位姿，有限步长和后续关节裁剪不能解释为精确的视觉等式约束。

**目前没有“视觉已够用，因此放松相机完整位姿约束”的机制。** 诊断满足阈值，也不会自动改变 `J_L` 的行数。

### 3.5 C 基座合成惯性反作用

对模块质心计算：

\[
J_{v,i}^{(j)}=a_j\times(r_i-o_j),\qquad J_{\omega,i}^{(j)}=a_j
\]

（不在该模块祖先链上的关节列为零）。同一坐标系和同一 C 原点下，每个模块贡献：

\[
A_i=\begin{bmatrix}m_iJ_{v,i}\\I_i^{world}J_{\omega,i}+[r_i-r_C]_\times m_iJ_{v,i}\end{bmatrix}.
\]

两臂求和并转到 C 坐标轴：

\[
H_C=A(q)\dot q,\qquad W_C=\begin{bmatrix}F_C\\\tau_C\end{bmatrix}=-\frac{dH_C}{dt}=-(A\ddot q+\dot A\dot q).
\]

实现用沿速度方向的中心差分求偏置项：

\[
\dot A\dot q\approx\frac{A(q+h\dot q)-A(q-h\dot q)}{2h}\dot q,\quad h=10^{-5}/\max(1,\|\dot q\|).
\]

固定连接模块按平行轴定理聚合以省计算，审计则用原始逐刚体 Newton–Euler 计算作独立对照。左右臂不能在各自镜像基座坐标系直接相加，必须统一至 C 坐标系。

反力 N、力矩 N·m 与冲量不同。演示中线冲量为：

\[
J_F(t)=\left\|\int_{\max(0,t-0.25)}^t F_C(\xi)d\xi\right\|,
\]

单位 N·s；日志按控制区间重叠长度积分。整次静止到静止运动的净冲量接近零并不说明中间没有冲击，因此同时报告峰值、RMS 和短滑窗冲量。

### 3.6 几何规划、连续检查、时间缩放

先对右臂子目标做关节空间规划和路径缩短，再加入左臂候选；左臂位移按 `1, 0.5, 0.25, 0` 尝试，通过后才允许执行。若另一臂已移动，则针对其新姿态重新规划，不继续信任旧的静止另一臂路径。

对关节线段形成包围盒，在盒中心计算 CAD 几何，用关节扰动引起的保守几何位移界膨胀碰撞体。能证明整个盒安全则接受；否则递归二分，达到深度预算仍不能证明便拒绝。右臂检查包含另一臂的运动界以及负载，因此不是只检查两臂若干离散姿态。

认证后的几何线段执行五次时间律：

\[
q(t)=q_0+(q_1-q_0)s(u),\quad u=t/T,\quad s(u)=10u^3-15u^4+6u^5.
\]

令 `d=max_i |q1_i−q0_i|`：

\[
T\ge\max\left(0.1,\frac{1.875d}{0.30},\sqrt{\frac{5.773502692d}{0.50}},\sqrt[3]{\frac{60d}{5.0}}\right).
\]

速度、加速度、jerk 上限分别为 0.30 rad/s、0.50 rad/s²、5 rad/s³；段端速度和加速度为零，保证段间 C2。

每段再取 21 点估计反作用峰值，时间伸长因子：

\[
k=1.02\max\left(1,\sqrt{F_{max,sample}/0.35},\sqrt{\tau_{max,sample}/0.15}\right),\quad T'=kT.
\]

固定几何路径上 `v'=v/k, a'=a/k², W'=W/k²`。所以减速能降低惯性反作用，但代价是时间增加。0.35 N、0.15 N·m 是采样设计目标，不是连续解析上界。

### 3.7 在线执行和失败处理

```text
初始化相机观测（不等待完整环境建图）
启动独立 RGB-D / 目标估计 / TSDF 进程（异步模式）
for 每件已知任务身份的零件:
    获取新鲜视觉中心，否则重新观测；仍失败则保持/退出
    for 预抓取、分段接近、抬升、递送、放置、撤离:
        根据最新估计/吸附状态产生右臂子目标
        规划右臂路径
        生成左相机目标 + 完整位姿零空间动量修正
        证明双臂与负载整段几何安全；失败则缩小左臂动作/重规划
        计算五次时间律和反作用时间缩放
        while 本段未结束:
            计算同一时刻左右臂 q, v, a
            估计 C 基座合成 W；下发运动学参考
            异步接收最新视觉，不把过期测量用于下一次视觉修正
            已检测感知异常/停机请求 → 同一认证路径内 C2 制动
        在段末静止状态获取下一段规划结果
    近距确认吸附/放置；更新地图版本
保存轨迹、观测、反作用、计算时延；独立审计
```

有限规划时间内找不到解只能停止，不能据此证明解不存在。当前在线执行也不是对每帧像素充分性进行硬门控；短暂失去有效目标可能先完成已认证的已知几何段，在下一次视觉目标更新处才触发保持。上述结构不构成动态环境下的递归可行性证明。

## 4. 真正的“足够看清即可释放”应如何定义（尚未实现）

建议用一个集合替代相机完整位姿等式：

\[
\mathcal V=\{q_L: g_{FOV}\ge0,\ d_{min}\le d\le d_{max},\ N_{vis}\ge N_{min},\lambda_{max}(\Sigma)\le\sigma_{max}^2,\ age\le age_{max}\}.
\]

只有接近边界的视觉约束才限制相机运动，在集合内部不用强制相机位置和朝向回到唯一目标。可在局部优化中最小化 `||D(Aa+b)||² + lambda||a||²`，同时满足右臂任务、视觉集合、碰撞、关节和制动约束。活跃视觉约束的 Jacobian 为 `J_active`，释放空间才应对应 `I−J_active^+J_active`，而不是始终用完整 6D 相机 Jacobian。

像素点数和遮挡存在不连续变化，不能直接把它们当作光滑 CBF 而宣称有证明。需要保守视域/深度裕量、可验证的局部近似、测量延迟和误差预算。`sigma_max` 应来自抓取容差、磁吸容差及标定误差的分配，并按任务阶段切换：抓取阶段要精确看目标，已吸附递送阶段不必一直看到被磁吸头盖住的圆盘。

若要进一步声称有限算力下持续可行，还需定义规划超时的安全后备轨迹、终端安全集合，以及感知和障碍变化的界。不能只给一个平均求解时间就跳过这些条件。

反作用视觉伺服本身已有多臂研究，不能把“视觉伺服 + 冗余 + 反作用”这个组合直接当新方法。参见 [Reactionless visual servoing of a multi-arm space robot combined with other manipulation tasks](https://www.sciencedirect.com/science/article/pii/S0921889016301208)。可见性和遮挡约束也已有研究，例如 [Occlusion-Free Image Based Visual Servoing using Probabilistic Control Barrier Certificates](https://arxiv.org/abs/2309.03476)。潜在贡献应落在**任务充分视觉的可验证自由度释放规律，以及它与合成反作用、可行性和计算预算之间的定量关系**；尚需系统文献对比和消融实验确认新颖性。

## 5. 动图与曲线的解释

文件：`reports/cooperative_dashboard/dashboard.gif`，标准三零件场景的全任务回放，约 8 倍速。不是实时 GUI 视频，也不是随机组最好的一次被偷偷选来替代总体结果。

- 场景：用记录的双臂关节角和物体姿态回放 USD 几何。
- RGB：实际曝光图，允许全幅/ROI 尺寸变化；标题写明曝光时间。
- TSDF：运行时保存的实际历史地图快照，约每 2 仿真秒保存一次，地图版本变化立即保存；不用最终地图倒填过去画面。
- 反力：Fx/Fy/Fz 和模长；力矩：合成模长；信息栏另给 0.25 s 线冲量。
- 视觉引导：TCP 到当前新鲜视觉估计目标的距离，不是与真值对比的定位误差。失去观测留空，不补成零；换零件会跳变。
- 建图曲线：已融合表面点数。吸附/放置清图导致下降是版本更新，不是把后来的观测拼成一条虚假的单调增长曲线。
- 质量 0/1：仅诊断使用，条件为新鲜目标、距离 0.45–1.20 m、支持点数至少 12、最大位置标准差不超过 5 mm、归一化像面坐标 `|u|≤0.60, |v|≤0.33`。它不是经实物验证的最小必要阈值，也没有接入当前控制硬约束。无活动目标或携带时圆盘被遮住，标为“不足/不适用”。
- 图中的单步计算时间包括本次同步感知/遥测开销，不能拿它替代独立异步版本的周期预算测量。

保存了 `telemetry/observations.json`、曝光 PNG 和地图 NPZ，以及 `dashboard_alignment.json`，可逐帧核对所有被显示观测/地图时间均不晚于回放时刻。

## 6. 随机实验协议

每个场景三件物品、两个固定种子 101 和 202，四组因子。任务身份和颜色已知，磁吸接口保持水平圆盘、半径 20 mm。物体数量不随机，也不是任意无标记物体识别。

| 因子 | 抽样范围 |
| --- | --- |
| 平面上物块中心位置 | 世界 x∈[0.515,0.660] m，y∈[−0.550,−0.180] m；间距拒绝采样 |
| 物块形状 | box、cylinder、hex_prism、wedge 离散随机 |
| 外形参数 | XY 尺寸参数各 42–66 mm，高度 32–58 mm；圆柱直径使用两个 XY 参数的较小值 |
| 朝向 | 绕竖直轴 −180° 至 180°；不随机倾斜标准磁吸接口 |
| 台面高度 | 水平工作台顶面 0.72–0.80 m；摆放台和操作台一起调整，槽位随动 |

外形随机保留标准对接接口，属于机身外形变化；楔形的对接面仍水平，用统一刚体描述接口与机身，未细化其安装支撑连接件。

可达域用 CAD 真值进行**离线预抓取端点 IK 筛查**：在已知参考左臂姿态下，检查每个目标上方 11 cm 的无碰撞右臂 IK。这个筛查不向在线视觉估计器提供真值目标，也不保证整段搬运、视角或其他左臂姿态始终可行。所有采样、拒绝、超时和停止保留，不按任务成功反复换种子。

运行时使用各自真实随机 USD，重新构建 CAD 碰撞模型。成功后另跑独立全路径审计；并行运行的壁钟时间不作为实时性证据。每组只有两例，是小样本功能测试，不能解释为总体成功率或大范围泛化结论。

首轮 `randomized_pilot_01` 的高度/联合组发现生成器错误：源场景台面父 prim 未声明 Xform，单独赋 xformOp 没有真正移动台面。已修正为显式 `UsdGeom.Xform.Define`，新增真实台面世界高度测试。首轮高度/联合结果无效并保留；同种子在 `randomized_pilot_02` 重跑，不把无效失败归因于控制算法。首轮位置/外形组不改变高度，不受该问题影响。

最终数值见本文件末尾的结果节与 `reports/randomized_scene_evaluation.json`。
