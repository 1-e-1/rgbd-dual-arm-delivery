# VLM 接入、系统输入输出与实用边界

更新日期：2026-09-11。本文件描述新增的受约束 VLM 接口和当前 RGB-D 控制主干；不把一次开发测试当成新方法有效性或实物可靠性的证明。最终实测数据见本文末尾及 `reports/rgbd_vlm_transfer_01`。

## 1. 系统究竟解决什么问题

给定一个明确的零件递送任务，在固定宇航员和 C 形支架、环境近似静止的微重力仿真中，用左臂相机提供环境测量和目标跟踪，右臂完成磁吸递送。在满足最低必要视觉质量与整段避碰要求时，允许左臂不再严格锁定某一个相机姿态，利用这部分运动余量尽量降低两臂共同施加于 C 形件的惯性反作用。

核心问题不是“让大模型看懂所有物体”，而是“为了完成当前操作，视觉已经足够好时，怎样把视觉臂的剩余运动能力用来减小基座扰动，并在观测不足时安全停止或补看”。

本次实际测试使用工程现有的 USD 几何、NVIDIA Warp 射线 RGB-D 传感器及 Python 运动学控制，不是实物相机采集，也不是 Isaac Sim/PhysX 全动力学接触实验。模型加载和 VLM 推理则确实在本机 GPU 上执行，并非用预设文本模拟。

当前主干是测量建图、有限预算 IK、小型 QP、轨迹验证和执行反馈。没有正在运行的 PPO、CFM、drifting 或世界模型；新增 VLM 仅为可替换的上位机模块，不训练它，也不让它接管控制器。

## 2. 输入与输出

| 层级 | 实际输入 | 实际输出 | 明确禁止或尚未支持 |
|---|---|---|---|
| 任务接口 | 固定动作类型 `transfer_one_marked_object`；英文目标描述；当前测得接口的 RGB 裁剪图 | 一个候选接口标签；核验后绑定测量身份；调用既有状态机模板 | 不是任意自然语言规划；不是 VLM 直接输出 3D 坐标、关节角或可执行代码 |
| 视觉建图 | RGB、深度、K、相机标定外参、编码器 FK、时间戳；保留原始记录的初始扫描 | TSDF、已证自由/未知/占据证据、测得三角曲面、法向及曲率信息 | 不用环境 CAD 补盲区；不将未观测区域补成自由空间；不保证封闭完整物体 |
| 视觉引导 | 当前目标接口和放置标记的测量、协方差、像素支持、数据年龄 | 当前目标位置、接近方向约束、视觉质量条件、需要补看的信息 | 不知道隐藏物体真实数量；不支持任意无标记物体的通用抓取姿态估计 |
| 双臂控制 | 上述测量与地图；16 个关节状态；机器人自身几何/运动学；质量、质心、惯量；磁吸反馈 | 左右各 8 关节的同步时间参数化运动、状态切换、继续/制动/停止决策 | 环境真值仅供事后审计；不允许 VLM 放宽避碰和视觉阈值 |
| 性能输出 | 记录的轨迹、图像、地图、模型参数；独立仿真审计 | 任务完成状态、放置误差、碰撞验证、C 形件模型反力/力矩、时间与资源开销 | 模型反力不是实测冲击力；仿真成功不等于硬件安全认证 |

“完全由 RGB-D”指环境几何和目标位置的控制依据完全来自 RGB-D，不是说不需要编码器、相机标定、机器人自身几何和质量参数。

本次 VLM 输入为 D435i 仿真中配准到深度坐标的 RGB 图像裁剪，而不是无结构点云直接输入。裁剪位置来自 RGB-D 测得接口的投影，图中只标 A/B/C，不向模型提供场景真值、物体真实坐标或语义名称。完整原始 RGB-D、裁剪范围、提示词、未经修改的模型回复和模型权重哈希均保存。

## 3. 运行过程

```text
任务类型 + 用户目标描述
        ↓
原始 RGB-D 初始扫描重放 → 检查起始机器人位置是否有足够自由空间证据
        ↓
腕部当前 RGB-D → 测得候选接口 → VLM 选 A/B/C 或弃权
        ↓
格式、图像哈希、已知接口颜色属性核验；不符则停止，不替模型改答案
        ↓
卸载 VLM 进程 → 新 RGB-D 重新绑定目标身份和位置
        ↓
接近 → 吸附反馈确认 → 抬升 → 搬运 → 放置 → 释放反馈确认 → 撤离
        ↕ 每个阶段内循环
当前 RGB-D/目标质量 + 地图 → 右臂候选 → 左臂视觉余量分配
        → 联合避碰/视觉/反作用限制验证 → 同步执行或制动/补看
        ↓
局部地图更新 + 任务结果 + 独立轨迹/载荷/放置/时间戳审计
```

VLM 是任务开始时调用的慢速服务，推理完成后退出进程，释放显存；它不在每个控制周期运行。两臂在通过验证的联合运动段内同步运动，不是“左臂全部建图结束后右臂才动”。但规划、全帧建图提交和记录写盘仍会在 C2 静止端点进行，因此不能称为全栈持续硬实时。

放置点不是 VLM 幻想出的坐标：既有控制器从测得的可用放置标记中选择位置，再以 RGB-D 验证支撑面和周边空间。状态机由本地已有模板给出，不是声称本次小模型自主编写了完整状态机。

## 4. 核心计算与协调含义

深度像素在本工程 OpenGL 相机坐标系中反投影为：

\[
p_W=R_{WC}[(u-c_x)d/f_x,\;-(v-c_y)d/f_y,\;-d]^T+t_{WC}.
\]

`T_WC` 来自标定和左臂编码器 FK，不读取目标真值位姿。目标位置从接口像素与深度估计，同时保留协方差和原始曝光时间。地图中的未知区域维持禁止状态，而非根据点云“那里没有点”就判为空。

视觉不是锁死左臂全部位姿，而是一个可行集合：

\[
\mathcal V=\{q_L: \text{投影在安全视野内，距离、视角、像素支持、估计误差满足阈值}\}.
\]

当前默认质量条件包括：目标至少 12 个有效像素、最大位置标准差 5 mm、反馈年龄不超过 0.25 s、相机到目标约 0.45–1.20 m。几何投影和像素预测是局部代理量，实际执行仍要求新鲜图像反馈，不能用代理量证明永不遮挡。

两臂动量在共同 C 坐标系中相加。令 \(H_L,H_R\) 为各臂的动量矩阵：

\[
w_C=-\left(H_L\ddot q_L+\dot H_L\dot q_L+H_R\ddot q_R+\dot H_R\dot q_R\right).
\]

左臂局部八变量 QP 在视觉集合和关节步长约束内提出减小组合反作用的运动；真实非线性联合轨迹还要经过几何、视觉和反作用检查。不要求两臂简单镜像或速度相反：各姿态下的惯量和力臂不同，必须在同一坐标系计算合成效果。可行集合受限时，零反作用可能不存在；现阶段目标是降低特定反作用指标，不能保证每时刻为零或所有峰值都下降。

避碰同时检查机器人自身/双臂/C 形件已知几何，以及 RGB-D 测得环境中的整段扫掠空间。目标物体也属于碰撞对象，只有测得且受限的磁吸接触区域和放置支撑接触被单独授权。拿起后，测得载荷几何随右臂参与避碰，不是从世界中消失。

更新地图时仅撤销已变化区域中过时的占据和自由证据，其余区域保留；没有新证据时不能凭空增加自由空间。测得的载荷表面随刚性吸附变换保存。具体差分、梯度、Hessian、轨迹参数化见 `CURRENT_RGBD_TECHNICAL_ROUTE.md`。

## 5. 小型 VLM 的接入结果与限制

使用官方 [HuggingFaceTB/SmolVLM-500M-Instruct](https://huggingface.co/HuggingFaceTB/SmolVLM-500M-Instruct)，模型卡标注 Apache-2.0，主要语言为英语。下载修订号 `a7da5b986cb59b408707209984f360a5f4ad7e47`；权重 SHA-256 `d05b567eeaf534e83d375551f068ed57b5f52d37c657197f644af5ef9db091a2`。仅本地 safetensors 推理，禁用远程自定义代码，推理不访问网络，也不上传场景数据。未升级原仿真环境。

本机 RTX 5070 Ti 的总显存为 16,303 MiB。开发探针实际模型推理约 0.43–0.67 s，模型进程 PyTorch 峰值分配约 1,352 MiB、峰值预留 1,496 MiB；不包含仿真、显示和 CUDA 驱动。整个子进程启动还需额外时间，不能把纯生成时间当成上位机全部延迟。

这些是提示词/接口开发探针，不是独立识别准确率测试集。当前接口只接受 `Select the red/green/blue interface.` 形式的明确目标选择。动作类型固定为递送一个物体，其他语言或动作请求直接拒绝。历史名称 `bolt/washer/bracket` 在随机场景中只是颜色接口身份，不能当成物体形状分类。

独立核验利用既有 RGB-D 接口颜色身份检查 VLM 是否选择了要求的颜色；它只拒绝错误，不替换 VLM 的答案。这个受限场景完全可以不用 VLM，直接做颜色选择。因此这次接入的意义是验证可插拔高层任务接口及风险隔离，而非证明 VLM 提高了建图、避碰或反作用性能。若后续需要“取某种工具”这样的无标记语义选择，仍需新的识别/身份绑定验证或人工确认，不能拿本测试外推。

## 6. 实用价值与不能越过的边界

适合的研究落点：预先测量过、相对静止的舱内工作区，具有已知磁吸接口的刚性零件，低速递送任务。视觉臂不是固定摄像头，而是既能补充观测、又可在视觉足够时承担组合反作用调节的辅助臂。

尚不能宣称：

- 任意未知工具/任意自然语言任务、自主选择任意抓取点、自由飞行或不断移动的物体、宇航员任意活动情况下安全工作。
- 不经预扫描便能从腕部空地图安全覆盖自身背后。当前预扫描来自模拟外部 RGB-D 采集，须场景不变且哈希/标定匹配；不是实物数据，也不是已验证的自主腕部初始化扫描。
- 完整动力学零反冲。宇航员和 C 形件固定、关节运动学驱动；摄像头/工具/载荷惯量按既定研究约定排除；COM/惯量来自模型；没有接触冲量、人体柔性和实测力验证。
- 全栈 60 Hz 硬实时、任意环境成功率高、所有反作用指标都优于固定视觉臂。
- 2 mm 体素就等于任意表面 2 mm 精度。可见表面精度、遮挡后侧覆盖率和可通行证据是不同指标。

已有独立随机场景保留测试为 24 场景 × 3 策略，共 72 次；set 与 pose 各完成 16/24，hold 完成 18/24。set 相对 hold 的共同成功场景可降低部分平均反作用指标，但峰值和时间不一定更好。失败中的有限预算 IK、视野交接、未知空间、局部地图预算，以及持有物体时的静态地图审计归属问题，仍限制系统实用性。本次接入不改变这些结论，也没有重写旧试验结果。
